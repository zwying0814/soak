# Soak 主题

## 🌟 主题简介

Soak 是一款基于开源框架 Astro 构建的博客主题，从底层就自带 "高性能" 基因。搭载了 Solid.js、Tailwind CSS 等前沿技术栈，在加载速度、页面流畅度上实现了对传统站点的超越，让你的博客既能 "颜值在线"，又能 "跑得飞快"。

### ✨ 核心特性

- **🚀 高性能架构**：基于 Astro 静态站点生成器，极致优化的加载速度
- **📝 MDX 原生支持**：突破传统 Markdown 限制，可直接嵌入交互组件
- **🎨 风格自由切换**：支持卡片风、简洁风等多种布局风格
- **🌙 智能主题切换**：支持明暗模式手动/自动切换，适配系统设置
- **📐 LaTeX 公式支持**：无需额外配置，完美渲染数学公式
- **🎯 语法高亮增强**：覆盖多语言代码高亮，支持 diff 语法对比
- **🔧 高度可定制**：导航栏、侧边栏、页脚等组件均可自由配置
